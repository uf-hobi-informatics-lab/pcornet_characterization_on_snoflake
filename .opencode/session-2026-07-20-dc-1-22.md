## SAS provenance

- **Row**: 1.22 (`edc_report.sas:4287`)
- **Description**: `'1.22'='Patients have multiple current physical addresses in the LDS_ADDRESS_HISTORY table'` (`edc_report.sas:4298`)
- **Exception text**: `11="A PATID has multiple ADDRESSIDs where CURRENT_ADDRESS_FLAG='Y'"` (`edc_report.sas:4312`)
- **Source metric**: `LDSADRS_L3_CURRENT` — generated by `%n_pct(dset=LDS_ADDRESS_HISTORY, var=CURRENT_ADDRESS_FLAG, qnam=ldsadrs_l3_current, distinct=y)` in `data_curation_tables.sas:3612`.
- **Fire predicate**: from `edc_report.sas:4613-4640` — for the `LDSADRS_L3_CURRENT` slice restricted to `category='Y'`:
  - `z10_distinct` = `DISTINCT_PATID_N` (distinct PATIDs with `CURRENT_ADDRESS_FLAG='Y'`)
  - `z10_record` = `RECORD_N` (rows with `CURRENT_ADDRESS_FLAG='Y'`)
  - `if z10_distinct < z10_record then flag`
- **Classification**: row 1.22 is a red exception (`edc_report.sas:11309`).

**Direct SQL translation:**
```
SELECT COUNT(*)              AS record_n,
       COUNT(DISTINCT PATID) AS distinct_patid_n
FROM   LDS_ADDRESS_HISTORY
WHERE  UPPER(TRIM(CURRENT_ADDRESS_FLAG)) = 'Y';
-- flag when record_n > distinct_patid_n
```

  - `CURRENT_ROW_N` — rows with `CURRENT_ADDRESS_FLAG='Y'` (SAS `z10_record`)
  - `CURRENT_PATID_DISTINCT_N` — distinct PATIDs in that slice (SAS `z10_distinct`)

  - `EXCESS_ROWS_N` = `CURRENT_ROW_N - CURRENT_PATID_DISTINCT_N` (SAS `z10_record - z10_distinct`)
  - `MULTI_CURRENT_FLAG` = 1 iff `EXCESS_ROWS_N > 0` (EXCEPTION_FLAG=TRUE on fire)
  - Terminal `STATUS`=`OK`.
- **Threshold**: `excess_rows_n_gt = 0`.
